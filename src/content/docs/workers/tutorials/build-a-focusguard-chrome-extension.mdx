In this tutorial, you will build FocusGuard: a Chrome extension that tracks time spent on each domain, lets you set daily browsing goals, blocks distracting sites during timed focus sessions, and visualizes your browsing history in an analytics dashboard.

By the end of this tutorial you will have a working Chrome extension with:

- Automatic per-domain time tracking that persists across browser sessions.
- A configurable blocklist enforced only when a focus session is active.
- Daily usage goals with visual progress indicators.
- A full-screen dashboard with bar and doughnut charts powered by Chart.js.
- A CSV export of your daily browsing data.

## 2. Create the manifest

The `manifest.json` file tells Chrome about your extension, which permissions it needs, and which files to use as the background service worker and popup.

Create `manifest.json`:

```json
{
  "manifest_version": 3,
  "name": "FocusGuard – Daily Tab & Time Tracker",
  "version": "1.0.0",
  "description": "Tracks time spent on each domain, sets daily focus goals, and blocks distracting sites during work sessions.",
  "permissions": [
    "storage",
    "tabs",
    "alarms",
    "scripting"
  ],
  "host_permissions": [
    "<all_urls>"
  ],
  "background": {
    "service_worker": "background.js"
  },
  "action": {
    "default_popup": "popup.html",
    "default_title": "FocusGuard"
  },
  "icons": {
    "16": "icons/icon16.png",
    "48": "icons/icon48.png",
    "128": "icons/icon128.png"
  }
}
```

Key points:

- `"manifest_version": 3` is the current standard for Chrome extensions.
- `"storage"` lets the extension use `chrome.storage.local` to persist data without a backend.
- `"tabs"` lets the extension read the URL of the active tab so it can track which domain is open.
- `"alarms"` lets the extension schedule periodic flushes of tracked time and trigger focus-session end events.

## 3. Build the background service worker

The background service worker (`background.js`) runs continuously in the background. It has two responsibilities:

1. Record how many seconds the user spends on each domain per day.
2. Redirect blocked domains to a blocked page when a focus session is active.

Create `background.js`:

```js
"use strict";

let activeTabId   = null;
let activeOrigin  = null;
let sessionStart  = null;

function extractDomain(url) {
  try {
    const u = new URL(url);
    if (u.protocol !== "http:" && u.protocol !== "https:") return null;
    return u.hostname.replace(/^www\./, "");
  } catch {
    return null;
  }
}

function todayKey() {
  const d = new Date();
  return `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,"0")}-${String(d.getDate()).padStart(2,"0")}`;
}

function flushTime() {
  if (!activeOrigin || !sessionStart) return;
  const elapsed = Math.floor((Date.now() - sessionStart) / 1000);
  if (elapsed < 1) return;

  const key = "usage_" + todayKey();
  chrome.storage.local.get({ [key]: {} }, (res) => {
    const usage = res[key];
    usage[activeOrigin] = (usage[activeOrigin] || 0) + elapsed;
    chrome.storage.local.set({ [key]: usage });
  });
  sessionStart = Date.now();
}

function startTracking(tabId, url) {
  flushTime();
  activeTabId  = tabId;
  activeOrigin = extractDomain(url);
  sessionStart = activeOrigin ? Date.now() : null;

  if (activeOrigin) checkBlock(activeOrigin, tabId, url);
}

function checkBlock(domain, tabId, url) {
  chrome.storage.local.get({ focusActive: false, blockList: [] }, (res) => {
    if (!res.focusActive) return;
    const blocked = res.blockList.some(b => domain === b || domain.endsWith("." + b));
    if (blocked) {
      const redirectUrl = chrome.runtime.getURL("blocked.html") +
        "?site=" + encodeURIComponent(domain);
      chrome.tabs.update(tabId, { url: redirectUrl });
    }
  });
}

chrome.tabs.onActivated.addListener(({ tabId }) => {
  chrome.tabs.get(tabId, (tab) => {
    if (chrome.runtime.lastError || !tab.url) return;
    startTracking(tabId, tab.url);
  });
});

chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => {
  if (changeInfo.status === "complete" && tab.active) {
    startTracking(tabId, tab.url || "");
  }
});

chrome.tabs.onRemoved.addListener((tabId) => {
  if (tabId === activeTabId) flushTime();
});

chrome.alarms.create("flush", { periodInMinutes: 0.5 });
chrome.alarms.onAlarm.addListener((alarm) => {
  if (alarm.name === "flush") flushTime();
  if (alarm.name === "focusEnd") {
    chrome.storage.local.set({ focusActive: false });
  }
});
```

### How time tracking works

The service worker maintains three variables — `activeTabId`, `activeOrigin`, and `sessionStart` — to track the currently active tab.

Whenever the active tab changes (via `onActivated` or `onUpdated`), `flushTime` is called first to write elapsed seconds to storage, and then the variables reset for the new tab. A `"flush"` alarm fires every 30 seconds as a safety net to avoid losing time if the browser closes unexpectedly.

Time is stored in `chrome.storage.local` under a key like `usage_2026-05-23`, which is an object mapping domain strings to accumulated seconds.

### How blocking works

`checkBlock` reads `focusActive` and `blockList` from storage. If the current domain matches any entry in the blocklist (including subdomains), Chrome redirects the tab to `blocked.html` with the blocked domain passed as a query parameter. Blocking is only active when a focus session is running, so the user can browse freely outside of focus time.

```js
"use strict";

function todayKey() {
  const d = new Date();
  return `usage_${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,"0")}-${String(d.getDate()).padStart(2,"0")}`;
}

function fmtTime(seconds) {
  if (seconds < 60) return seconds + "s";
  const h = Math.floor(seconds / 3600);
  const m = Math.floor((seconds % 3600) / 60);
  const s = seconds % 60;
  if (h > 0) return `${h}h ${m}m`;
  return `${m}m ${s}s`;
}

function fmtCountdown(seconds) {
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;

}

function renderUsage(usage, goals) {
  const entries = Object.entries(usage).sort((a, b) => b[1] - a[1]);
  if (entries.length === 0) {
    usageList.innerHTML = '<p class="empty-msg">No browsing data for today yet.</p>';
    totalToday.textContent = "";
    return;
  }

  const maxSec   = entries[0][1];
  const totalSec = entries.reduce((a, e) => a + e[1], 0);
  totalToday.textContent = "Total: " + fmtTime(totalSec);

  usageList.innerHTML = "";
  entries.forEach(([domain, secs]) => {
    const limitSecs = goals[domain] ? goals[domain] * 60 : null;
    const pct       = Math.min(100, Math.round((secs / maxSec) * 100));
    const overGoal  = limitSecs && secs > limitSecs;
    const nearGoal  = limitSecs && !overGoal && secs > limitSecs * 0.8;

        <span class="usage-domain">${domain}</span>
        <span class="usage-time">${fmtTime(secs)}${limitSecs ? " / " + fmtTime(limitSecs) : ""}</span>
      </div>
      <div class="usage-bar-bg">
        <div class="usage-bar-fill ${barClass}" style="width:${pct}%"></div>
      </div>

    usageList.appendChild(row);
  });
}

    btnFocus.textContent = "Start Focus";
    btnFocus.classList.remove("stop");
    focusMinInput.disabled = false;
    focusCountdown.textContent = "";
    clearInterval(countdownInterval);
  }
}

btnFocus.addEventListener("click", () => {
  chrome.storage.local.get({ focusActive: false }, (res) => {
    if (res.focusActive) {
      chrome.alarms.clear("focusEnd");
      chrome.storage.local.set({ focusActive: false, focusEndsAt: null }, loadAll);
    } else {
      const mins   = Math.max(1, parseInt(focusMinInput.value) || 25);
      const endsAt = Date.now() + mins * 60 * 1000;
      chrome.alarms.create("focusEnd", { delayInMinutes: mins });
      chrome.storage.local.set({ focusActive: true, focusEndsAt: endsAt }, loadAll);
    }
  });
});

function loadAll() {
  chrome.storage.local.get(
    { [todayKey()]: {}, blockList: [], goals: {}, focusActive: false, focusEndsAt: null },
    (res) => {
      renderUsage(res[todayKey()], res.goals);
      renderBlockList(res.blockList);
      renderGoals(res.goals);
      updateFocusUI(res.focusActive, res.focusEndsAt);
    }
  );
}

btnDash.addEventListener("click", () => {
  chrome.tabs.create({ url: chrome.runtime.getURL("dashboard.html") });
});

dateLabel.textContent = todayDateLabel();
loadAll();
setInterval(loadAll, 5000);
```

### Create dashboard.js

```js
"use strict";

let barChart = null;
let pieChart = null;

const COLORS = [
  "rgba(108,99,255,0.8)", "rgba(74,222,128,0.8)", "rgba(251,191,36,0.8)",
  "rgba(248,113,113,0.8)", "rgba(56,189,248,0.8)", "rgba(251,146,60,0.8)",
  "rgba(167,139,250,0.8)", "rgba(244,114,182,0.8)"
];
const BORDERS = [
  "rgb(108,99,255)", "rgb(74,222,128)", "rgb(251,191,36)",
  "rgb(248,113,113)", "rgb(56,189,248)", "rgb(251,146,60)",
  "rgb(167,139,250)", "rgb(244,114,182)"
];

function fmtTime(seconds) {
  if (seconds < 60) return seconds + "s";
  const h = Math.floor(seconds / 3600);
  const m = Math.floor((seconds % 3600) / 60);
  const s = seconds % 60;
  if (h > 0) return `${h}h ${m}m`;
  return `${m}m ${s}s`;
}

function buildDateKey(dateStr) { return "usage_" + dateStr; }

function getAvailableDates(allKeys) {
  return allKeys
    .filter(k => k.startsWith("usage_"))
    .map(k => k.replace("usage_", ""))
    .sort((a, b) => b.localeCompare(a));
}

function populateDateSelector(dates) {
  const sel = document.getElementById("date-select");
  sel.innerHTML = "";
  if (dates.length === 0) {
    const opt = document.createElement("option");
    opt.textContent = "No data yet";
    sel.appendChild(opt);
    return;
  }
  dates.forEach(d => {
    const opt = document.createElement("option");
    opt.value = d;
    const label = new Date(d + "T12:00:00").toLocaleDateString("en-US",
      { weekday:"short", month:"short", day:"numeric", year:"numeric" });
    opt.textContent = label;
    sel.appendChild(opt);
  });
}

function updateStats(usage, goals) {
  const entries   = Object.entries(usage).sort((a,b) => b[1]-a[1]);
  const totalSec  = entries.reduce((a,e) => a + e[1], 0);
  const exceeded  = entries.filter(([d, s]) => goals[d] && s > goals[d] * 60).length;
  const topDomain = entries.length > 0 ? entries[0][0] : "—";

  document.getElementById("s-total").textContent    = totalSec > 0 ? fmtTime(totalSec) : "0s";
  document.getElementById("s-domains").textContent  = entries.length;
  document.getElementById("s-exceeded").textContent = exceeded;
  document.getElementById("s-top").textContent      = topDomain;
}

function renderTable(usage, goals) {
  const tbody    = document.getElementById("domain-table");
  const emptyMsg = document.getElementById("empty-msg");
  tbody.innerHTML = "";
  const entries  = Object.entries(usage).sort((a,b) => b[1]-a[1]);

  if (entries.length === 0) { emptyMsg.style.display = "block"; return; }
  emptyMsg.style.display = "none";

  entries.forEach(([domain, secs]) => {
    const limitSecs   = goals[domain] ? goals[domain] * 60 : null;
    const pct         = limitSecs ? Math.min(100, Math.round((secs / limitSecs) * 100)) : null;
    const over        = limitSecs && secs > limitSecs;
    const statusBadge = limitSecs
      ? (over ? '<span class="badge-goal">Over Limit</span>' : '<span class="badge-ok">On Track</span>')
      : '<span style="color:var(--muted);font-size:11px;">No goal set</span>';
    const barHtml = limitSecs
      ? `<div class="mini-bar-bg"><div class="mini-bar-fill ${over ? "over" : ""}" style="width:${Math.min(100,pct)}px;"></div></div>`
      : `<span style="color:#64748b;font-size:11px;">—</span>`;

    const tr = document.createElement("tr");
    tr.innerHTML = `
      <td><strong>${domain}</strong></td>
      <td>${fmtTime(secs)}</td>
      <td>${limitSecs ? fmtTime(limitSecs) : "—"}</td>
      <td class="progress-cell">${barHtml}</td>
      <td>${statusBadge}</td>
    `;
    tbody.appendChild(tr);
  });
}

function destroyCharts() {
  if (barChart) { barChart.destroy(); barChart = null; }
  if (pieChart) { pieChart.destroy(); pieChart = null; }
}

function renderCharts(usage) {
  destroyCharts();
  const entries   = Object.entries(usage).sort((a,b) => b[1]-a[1]).slice(0, 8);
  const labels    = entries.map(e => e[0]);
  const values    = entries.map(e => e[1]);
  const barCanvas = document.getElementById("bar-chart");
  const pieCanvas = document.getElementById("pie-chart");

  if (entries.length === 0) {
    barCanvas.parentNode.innerHTML = '<p style="color:#64748b;text-align:center;padding:40px 0;font-size:13px;">No data for this date.</p>';
    pieCanvas.parentNode.innerHTML = '<p style="color:#64748b;text-align:center;padding:40px 0;font-size:13px;">No data for this date.</p>';
    return;
  }

  barChart = new Chart(barCanvas, {
    type: "bar",
    data: {
      labels,
      datasets: [{
        label: "Seconds", data: values,
        backgroundColor: COLORS.slice(0, labels.length),
        borderColor: BORDERS.slice(0, labels.length),
        borderWidth: 2, borderRadius: 6, borderSkipped: false
      }]
    },
    options: {
      responsive: true, maintainAspectRatio: false,
      plugins: {
        legend: { display: false },
        tooltip: { callbacks: { label: (ctx) => " " + fmtTime(ctx.parsed.y) } }
      },
      scales: {
        x: {
          grid: { color: "rgba(255,255,255,0.04)" },
          ticks: {
            color: "#64748b", font: { size: 10, family: "inherit" }, maxRotation: 30,
            callback: function(val) {
              const l = this.getLabelForValue(val);
              return l.length > 12 ? l.substring(0,10) + "…" : l;
            }
          }
        },
        y: {
          grid: { color: "rgba(255,255,255,0.04)" },
          ticks: { color: "#64748b", font: { size: 10 }, callback: (v) => fmtTime(v) },
          beginAtZero: true
        }
      }
    }
  });

  pieChart = new Chart(pieCanvas, {
    type: "doughnut",
    data: {
      labels,
      datasets: [{
        data: values,
        backgroundColor: COLORS.slice(0, labels.length),
        borderColor: "#1a1d27", borderWidth: 3, hoverOffset: 10
      }]
    },
    options: {
      responsive: true, maintainAspectRatio: false,
      plugins: {
        legend: {
          position: "bottom",
          labels: { color: "#94a3b8", font: { size: 10, family: "inherit" }, padding: 12, usePointStyle: true, pointStyleWidth: 8 }
        },
        tooltip: {
          callbacks: {
            label: (ctx) => {
              const total = ctx.dataset.data.reduce((a,b) => a+b, 0);
              const pct   = ((ctx.parsed / total)*100).toFixed(1);
              return ` ${ctx.label}: ${fmtTime(ctx.parsed)} (${pct}%)`;
            }
          }
        }
      }
    }
  });
}

function exportCSV(usage, goals, dateStr) {
  const rows = [["Domain","Time (seconds)","Time (formatted)","Daily Goal (min)","Status"]];
  Object.entries(usage).sort((a,b) => b[1]-a[1]).forEach(([domain, secs]) => {
    const goalMins = goals[domain] || "";
    const status   = goals[domain]
      ? (secs > goals[domain]*60 ? "Over Limit" : "On Track")
      : "No Goal";
    rows.push([domain, secs, fmtTime(secs), goalMins, status]);
  });
  const csv  = rows.map(r => r.map(c => `"${c}"`).join(",")).join("\n");
  const blob = new Blob([csv], { type: "text/csv" });
  const url  = URL.createObjectURL(blob);
  const a    = document.createElement("a");
  a.href = url; a.download = `focusguard_${dateStr}.csv`;
  document.body.appendChild(a); a.click();
  document.body.removeChild(a);
  URL.revokeObjectURL(url);
}

function loadForDate(dateStr) {
  const key = buildDateKey(dateStr);
  chrome.storage.local.get({ [key]: {}, goals: {} }, (res) => {
    const usage = res[key];
    const goals = res.goals;
    updateStats(usage, goals);
    renderTable(usage, goals);
    renderCharts(usage);
    document.getElementById("btn-export").onclick = () => exportCSV(usage, goals, dateStr);
  });
}

function init() {
  chrome.storage.local.get(null, (all) => {
    const keys  = Object.keys(all);
    const dates = getAvailableDates(keys);
    populateDateSelector(dates);
    const sel = document.getElementById("date-select");
    sel.addEventListener("change", () => loadForDate(sel.value));
    if (dates.length > 0) loadForDate(dates[0]);
  });
}

document.addEventListener("DOMContentLoaded", init);
```

## 7. Load the extension in Chrome

To test the extension during development:

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode** in the top right corner.
3. Select **Load unpacked** and choose your `focusguard/` directory.
4. The FocusGuard icon will appear in the Chrome toolbar. Select it to open the popup.

To see time tracking in action, browse a few websites for a minute and then reopen the popup. Usage data appears under the **Today** tab.

## 8. Test focus sessions and blocking

To verify the blocking feature:

1. Open the **Block List** tab in the popup and add a site, for example `youtube.com`.
2. Set the focus duration to `1` minute and select **Start Focus**.
3. Open a new tab and go to `youtube.com`. Chrome should redirect you to the blocked page.
4. Select **Bypass Once** to confirm you can override the block, or select **Go Back** to return.
5. Wait for the focus session to expire, or select **Stop Focus** in the popup. The block is lifted immediately.

## Summary

You have built a Chrome extension with the following parts:

| File | Role |
| --- | --- |
| `manifest.json` | Declares permissions and entry points |
| `background.js` | Tracks time per domain; enforces blocklist during focus sessions |
| `popup.html` / `popup.js` | Popup UI: usage, blocklist, goals, and focus timer |
| `blocked.html` | Page shown when a blocked site is visited |
| `dashboard.html` / `dashboard.js` | Full-screen analytics dashboard with charts and CSV export |

From here you could extend FocusGuard by syncing data across devices using [Cloudflare Workers KV](/kv/) as a remote store, or by adding a daily report sent to a webhook using a [Cloudflare Worker](/workers/).
